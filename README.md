# écoute · 法语意群听力训练

React + TypeScript + Vite 静态网站，支持 DALF C1、工程法语与日常法语，按日期积累材料。内置示例明确标记，不冒充用户真实对话；Piste 37 使用用户提供的原音与文稿。

## 使用流程

三个独立训练页面，同一时间只显示一页，可通过上方步骤切换：

1. **整篇跟读**：完整音源、速度、循环、整篇录音。点击「查看整篇原文」展开连贯全文，以 `/` 和可点击的下划线区分意群；「查看当前解析」单独展开逐句中文、结构与听辨重点，两个按钮都可再次点击收起。右下角「开始跟读听辨」进入下一页。
2. **逐句听辨**：先点句子编号。各意群分别显示为卡片：点击法语区域单独展开/收起这一意群的文字与可用中文，不触发播放；点击「只听这一意群」只播放对应片段，不揭示文字。也可一键显示/隐藏本句全部原文。只保留一个当前跟读录音区：选句子录整句，点意群播放后录该意群。当前句解析在旁边展开/收起。
3. **习题测试**：取消听写，改为卡片式单词、词组、表达含义选择（最多8张）和表达排序（最多2题）。选择后即显示答案和原句语境，可重练未掌握词条；完成本轮后保存练习记录，有错时将本份材料加入错题复习。词义来自本地维护的词条表，只匹配当前材料中的词条；未知文本回退到原句表达识别，不虚构词义。当前尚未实现跨日间隔复习算法。

切换整份材料的按钮明确标为「下一个对话」，区别于句子编号和复习卡片的「下一张」。

原有短句示例已扩写成8轮场景对话，另新增12轮杜阿拉机场行李与接机场景；现有示例均至少8个句段。原句与译文保留在对话中，新增台词明确属于编写的示例，不冒充用户的历史经历。个人导入的原始积累保留，不擅自改写。真人时间轴保留，合成材料的意群与语调为句法建议，并非声学测量。

## 添加材料

点击「＋ 直接粘贴法语」，将标题、法语与中文一起粘贴到一个框中，无需 JSON。可先预览，也可直接识别并保存。例如：

```text
标题：确认设备进场
模块：工程法语
日期：2026-10-20
法语：Pourriez-vous confirmer la livraison ?
中文：您能确认送货吗？
法语：Oui, le matériel arrivera demain.
中文：是的，设备明天会到。
解析：条件式用于礼貌请求。
```

也支持无标签的中法交替行。识别在浏览器本地按规则完成，不自动翻译；中法句数不同时提示并保留整段中文，避免错误配对。可以展开可选的分栏输入、从 TXT 读取内容。Word/PDF 不直接解析。

「题库与数据」保留 JSON 导入、示例下载、备份导出和恢复；按 ID 及规范化法语全文去重。数据模型见 `src/data.ts`，`module` 为 `c1` / `engineering` / `daily`，材料支持日期、中文、备注以及句内注释。完整材料用 `format: "passage"`，`chunks` 每项代表一句；`prosody` 可指定句内边界和语调。

## 管理误导入的材料

每份练习卡片下方的小三角「移动 / 删除」菜单提供「所属模块」和「删除这份练习」。选错模块可直接调整，无需删除重录，学习记录保留。删除同时清理该材料的学习记录；刷新后不会重新出现。当前会话可「撤销删除」，恢复最近删除的一份材料及其学习记录。内置示例、内置原音课程和个人导入材料都可操作。删除记录随本地数据保存，内置内容也不会在刷新时自动恢复。

「题库与数据」中的「管理全部材料」也支持调整模块、删除与撤销。记录仅在自己的浏览器中，网站更新不会替用户直接操作已导入的内容。

## 录音、音源与本地数据

- 使用浏览器实际 `getUserMedia` 与 `MediaRecorder`，支持录制、立即回放、下载、删除，最长5分钟。处理权限拒绝、无设备、占用、不支持、空录音和录制失败。
- 麦克风要求 HTTPS 或 localhost。切句或翻页会停止正在录制的对应声音，同一材料中已录的整篇、单句、意群声音分别保留。离开材料或刷新后临时录音释放；需保留请下载。录音不上传、不包含在 JSON 备份中。
- 学习数据保存在当前浏览器 `localStorage`，不跨设备自动同步，建议导出备份。
- 内置示例现在优先使用已生成的MP3音频文件，整篇、单句、意群均可直接播放，不依赖系统法语声音或首次WASM下载。所有材料都显示可见的音频播放器，手机拦截自动播放时可直接点播放器重试。这些是基础合成音，韵律仍较机械，不是自然人声。
- 无预生成音频的个人文本优先使用浏览器法语语音，可选择设备声音。等待语音列表就绪后仍无可用法语声音时，自动切换到独立 Web Worker 中的 eSpeak-NG 基础法语合成，支持内置和新粘贴的文本，无需收费 API。初次按需下载约18 MB 的 WebAssembly 音源；后续可利用浏览器缓存。其音色和韵律较机械，界面明确标记，不是训练后的人声，也不能等同真人录音。音源加载失败会提示重试，不会静默无声。
- 备用引擎的许可及源码信息见 [public/notices/espeak-ng-source.txt](public/notices/espeak-ng-source.txt) 与 [GPL 许可](public/notices/espeak-ng-license.txt)。
- `audioUrl` 可在整篇或句子中指定 HTTPS 真人音源。带句/意群起止时间的真人素材使用 `lesson` 数据结构（见 `src/long-lesson.ts`、`src/lessons/piste37.json`）。上传的 Piste 37 边界为自动对齐，仍待人工听校，可在第二页调整本句起止时间；微调仅保存在本浏览器。
- `/`、`↗`、`↘`、`→` 是教学标注，不发送给合成器，不保证合成音会按箭头变化。
- 听辨重点来自材料原注释和本地常见语法/词组规则，任意新文本不会自动得到完整人工解析。独立语音模型训练的准备进展及阻塞见 [training/README.md](training/README.md)，目前没有已完成训练的模型。

## 部署

`npm run build` 生成 `dist/`，可发布到静态托管服务。Vite 使用相对资源路径，支持仓库子路径。

GitHub Pages：仓库设为支持 Pages 的可见性/套餐，在 Settings → Pages 将 Source 设为 GitHub Actions；仓库自带 `.github/workflows/deploy.yml`。推送 `main` 自动构建部署，也可在 Actions 手动运行。部署成功后访问：

https://weiyiaaa111.github.io/french-listening-trainer/

专用参数：`?lesson=piste37-complot` 直达上传材料，`?add=paste` 打开粘贴窗口。代码推送与线上部署完成是两个状态，需在 Actions 查看部署结果。

## 重新生成示例音频

`public/audio/samples/` 与 `src/sample-audio.json` 是随网站发布的示例音频及索引，不在用户浏览器临时生成。生成工具需要 ffmpeg 和支持 eSpeak C ABI 的本地引擎：

```bash
node scripts/export-sample-audio.mjs /tmp/ecoute-static-speech.json
python scripts/generate-sample-audio.py --input /tmp/ecoute-static-speech.json --engine /path/to/espeak-library.so --data /path/to/espeak-parent-directory
```

本次使用现有训练环境中 Piper 附带的 eSpeak-NG 引擎与法语语音数据生成，未调用收费服务，未训练新声音模型。普通安装、构建和部署不需要重新生成音频。
