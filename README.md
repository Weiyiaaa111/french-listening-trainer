# Écoute · 法语意群听力训练

React 19 + TypeScript + Vite 的响应式单页网站，无后端、无登录、无需收费 API。

## 本地开发与验证

需要 Node.js 22+（本次使用 Node 24）。

```sh
npm ci
npm run dev
npm run build
npm test
npx playwright install chromium
npm run test:e2e
npm run preview
```

开发服务默认端口 5173，预览端口 4173。使用开发服务器输出的地址访问。云端应通过平台转发端口预览；外网录音必须使用 HTTPS。若 npm 默认缓存不可写，可添加 `--cache /tmp/ecoute-npm-cache`。Linux 若缺浏览器系统库，执行 `npx playwright install --with-deps chromium`。

## 第一版功能

- DALF C1、工程法语、日常法语，均可按日期筛选。
- 28 道明确标为示例的练习（含三篇各 20 句的长篇材料），涵盖 ce qui / ce que / dont、lui / leur / les / la / en / y、过去时、否定、连接词。
- 三阶段：隐藏原文盲听、填写意群、显示参考原句 / 分割 / 中文与语法解析。
- 整句和意群播放、正常与慢速、循环；合成音不可用时有提示。
- 听写提交次数、最后练习时间和听写文本保存在记录中；页面显示累计次数。文本一致性比较仅忽略重音与标点，不是发音或意群评分。
- 错题收藏、已掌握、按模块复习。复习仅列出收藏且未掌握的句子。
- 浏览器真实录音，停止后立即回放与下载；录音最多五分钟，切换题目释放设备；盲听、听辨、原文阶段切换会保留本题录音。
- JSON 导入题库、导出格式示例、完整学习数据备份和恢复。

## 数据与真人音频

在「题库与数据」下载 JSON 示例；每题包括：

```json
{
  "id": "my-engineering-20261021-1",
  "module": "engineering",
  "date": "2026-10-21",
  "title": "采购确认",
  "translation": "你能把它们送到工地吗？",
  "sample": false,
  "tags": ["les"],
  "audioUrl": "https://example.com/sentence.mp3",
  "chunks": [
    {"text": "Pouvez-vous les livrer sur le chantier ?", "role": "直接宾语 les", "tip": "les 指已提及的物资。", "audioUrl": "https://example.com/chunk.mp3"}
  ]
}
```

导入文件是题目数组；完整备份为 `{ "items": [...], "progress": {...} }`。同 ID 或标准化法语全文重复会跳过，包含同文件内部重复；导入整体校验，错误不会部分保存。若要替换原题请使用新的 ID 和不同文本（本版不提供题目编辑器）。限制 5MB / 2000 题。音频地址须为可公开访问的 HTTP(S)，线上使用 HTTPS，确保有使用授权。整句和意群可以分别指定音频；没有地址时使用法语合成音。真人整句不会自动切分，需另行提供意群音频。

语音合成依赖操作系统和浏览器安装的法语语音包，部分语音需网络。合成音的韵律、连读、弱读不等于真人自然语流。无虚假评分。浏览器可能在首次载入语音时尚未就绪，可稍后重试。不同速度下需重新点击播放。

localStorage 记录不会跨设备同步；清理浏览器数据会丢失。请定期导出完整备份，换设备时导入。恢复时同 ID 练习记录以备份为准。录音只保留本次练习的内存 Blob，不上传，不随 JSON 备份；需要保存请单独下载。浏览器合成语音可能使用厂商在线服务。

## 部署

执行 `npm run build`，将 `dist/` 发布到任何 HTTPS 静态托管服务。

- Vercel / Netlify：构建命令 `npm run build`，输出目录 `dist`；无环境变量。
- GitHub Pages：本仓库内置 GitHub Actions；在仓库 Settings → Pages 选择 GitHub Actions，推送到 main 后构建部署。
- 相对资源路径支持仓库子路径；本项目无客户端多页路由，无需 rewrite。

不要公开暴露 Vite 开发服务作为生产网站。

## 测试范围与限制

Vitest 验证题库字段、导入原子性、去重、无效音频和文本比较。Playwright 验证隐藏原文、听写记录、刷新持久化、复习移除、日期筛选、坏文件提示、麦克风拒绝、真实 MediaRecorder 对测试音轨录制及 audio 回放、手机宽度布局。

自动化测试音轨不能代替实体麦克风。部署后仍需在手机 Safari、Android Chrome 和桌面浏览器上实测：首次授权/拒绝后恢复、蓝牙耳机、噪声环境、长时间录音、真实法语语音和 HTTPS 真人音频。第一版不提供自动发音评分、云同步、录音长期存储或间隔重复调度。

当前云环境已安装系统 Chromium，可直接运行 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`，无需下载浏览器。题库与数据窗口可查看每句的练习次数、日期与最近听写。


## 编号精听与录音管理更新

盲听和听辨阶段均可点击 01、02 等编号单独播放，不显示原文。听辨阶段可独立显示和隐藏当前片段的法语原文；「查看原文与解析」再显示全篇。长篇示例按完整句子切分，短句练习按意群切分；长篇时长取决于语音和语速，不声称固定三分钟。原有本地记录保留，新内置题库自动合并。录音回放旁可删除录音，删除会停止回放并释放临时音频地址，可继续重新录制。JSON 为练习文件格式，普通训练无需理解其技术字段。

## 上传的 Piste 37 真人原音

DALF C1 模块新增「真人原音｜阴谋论访谈 · 4 分钟」，使用用户提供的 `piste37.mp3`（约 4:03）和法语文稿。原音文件随站点部署；无需语音模型或收费 API。练习合计 29 道（28 道示例 + 1 道上传材料）。

- 整段播放器带真实时长、进度条、变速和循环。
- 35 个句段按钮使用同一份原音的起止秒数，不调用语音合成；124 个句内意群可逐个揭示法语、中文、语法说明和单独重听。
- 播放到句段/意群末尾会停止，循环时仅重放当前范围；拖动进度条超出当前范围会回到整段模式。
- `↗ / ↘ / →` **均为根据句法给出的朗读建议，未经原音音高核准**，不是音高测量结果，也不代表唯一读法。
- 时间轴使用本地 aeneas/eSpeak MFCC + DTW 自动对齐。初次结果因旧工具把重采样后的 16kHz 数据按 22.05kHz 拼接而出现零时长片段，修正本地工具采样率后重跑；不使用失败的时间轴。对齐时跳过约 9.8 秒片头和约 4 秒片尾。时间通过递增、非空、范围校验，但**仍未经逐句人工听校**。文稿省略、重叠说话及短意群可能影响边界准确性。
- 文稿中的 `[…]`、语气词及自我修正保留，不补写缺失内容；中文为学习用译文，语调标注为编辑建议。
- 发现截断可在「边界不准？」中调整本句起止秒数。仅本句边界可调整，意群仍用自动边界；本地调整独立保存，不包含在完整题库备份中。

课程数据在 `src/lessons/piste37.json`；部署原音在 `public/audio/piste37.mp3`。若重新对齐，可用 `python3 scripts/import_alignment.py <lesson.json> <aeneas-sync.json>` 验证并导入时间轴。aeneas 是此次整理素材的离线工具，不是网站安装或运行依赖。备份包含课程描述和音频路径，不把音频字节嵌入 JSON；换部署位置需同时保留音频文件。

本次验证：生产构建成功；11 项单元测试、11 项 Chromium 浏览器测试通过。包含原音真实时长、按句/意群跳转、边界停止、片段循环、逐个揭示/隐藏、语速、移动布局与专属链接。另通过生产预览确认 MP3 可加载。原音文本一致性、细致切点与实际语调仍需人工回听确认；自动化测试不等同于人工听校。

合成语音模型训练的独立进展、真实阻塞和复现步骤见 [training/README.md](training/README.md)。当前只完成候选数据和训练环境准备，尚无微调模型；线上音源未变更。


## 录音入口、完整材料和语调改进

录音组件固定在播放器下方，在所有模块和阶段都可见。保留真实录音、回放、下载、删除和重新录制；阶段切换不清除当前录音。新录音开始时停止原音播放，以便跟读。离开当前题目时仍会释放临时录音和麦克风；重要录音请下载。

工程、日常、C1 的三篇完整示例均为 20 个句段，完整材料优先排列，首页默认打开工程长篇。单句专项明确标注其意群数量。完整合成材料按句顺序播放，避免一条过长的合成请求；语调符号和角色标签不送进语音合成。浏览器真实语音包仍需设备实测，尚无已完成微调的声音模型。

语调朗读建议覆盖短句专项、完整示例与上传材料。可显示整句全部意群和箭头，也可继续逐个揭示。句内用 `/` 标边界，`↗ / ↘ / →` 分别表示上扬、下沉与延续。建议根据句法或人工意群边界生成，不是音高测量，不保证浏览器合成音会照箭头变化。上传原音及其自动时间轴不受这一界面改动影响。

本次改进验证：生产构建、15 项单元测试、16 项浏览器测试通过。新增检查覆盖三个模块录音入口、盲听→听辨→原文→盲听时录音不丢失、真实测试音轨回放与删除、整句多个语调符号，以及完整材料按顺序播放20句。手机实体麦克风和各系统语音包仍需设备实测。


## 整篇/单句跟读、统一原文与日常添加

所有练习都提供「查看整篇原文」「查看解析」的明确入口。Piste 37 也可显示完整35句的法语、中文和按意群组织的语法说明，默认仍隐藏。整篇录音入口保留在播放器附近。

编号区域下新增独立的单句/意群跟读区：可播放对应原音，再开始本句录音、回放、下载和删除。本题内切换编号会保留各句录音；正在录制的单句在切走时自动停止并生成回放。整篇与各句录音独立；启动一项录音会停止其他录音以避免同时占用麦克风。临时录音仍不上传、不包含在备份中，刷新或离开本题会释放，需保留时请下载。

日常模块增加5组8句场景示例（租房、看诊预约、转账核对、会议澄清、车辆安排），日常合计12份练习。示例不冒充用户历史记录。

添加自己的材料：点「＋ 添加 / 导入练习」，选择模块和日期，填写标题，粘贴法语（每行一句），中文和备注可选，然后保存。多行合为一份完整材料；单行可用 `/` 分意群。可以从 `.txt` 文本文档读取法语，再检查保存；复杂混排文档需先整理，当前不直接解析 Word/PDF。重复法语全文会跳过，数据只保存在当前浏览器，请导出备份。JSON 仍保留为结构化题库/备份导入方式，添加普通日常积累无需 JSON。

在设备提供多个法语声音时，可用「法语声音」选择器切换。声音自然度依赖设备语音包；句内语调符号仍是朗读建议，不是训练完成的证明。语音模型训练进展仍见 training/README.md。

本轮验证：生产构建、15 项单元测试、21 项 Chromium 浏览器测试通过，含整篇/单句录音独立保留、切句停止、单句删除不影响整篇、原文/解析切换、直接粘贴保存、TXT读取、刷新持久化及法语声音选择。实体设备麦克风仍需实测。

## 直接粘贴与听后口述入口

页面新增独立「＋ 直接粘贴法语」按钮，打开的是纯文本添加窗口，不渲染文件选择控件。也可用 `?add=paste` 直接打开窗口。文本框支持浏览器原生 Ctrl+V、⌘V、手机长按粘贴；不调用受权限限制的剪贴板读取 API。JSON 文件入口明确标注为选择文件，保留在题库与数据中。

口语练习不以听写为前置条件：编号精听面板内就能跟读或口头复述。完整合成材料还可拆到句内各意群，默认隐藏文字，每个意群都有播放、录音、回放和删除。Piste 37 的已揭示意群下方也提供就地录音，并有「隐藏文字，口头复述」。意群、单句和整篇分别保留临时录音，切换句子或隐藏文字不会清掉本题已录的意群音频；刷新、离开题目仍会释放，需要保留请下载。合成材料的句内片段使用合成音，上传材料的句内片段使用其自动对齐的真人原音。

本轮验证：生产构建、15项单元测试、26项 Chromium 浏览器测试通过。新增测试通过真实剪贴板 Ctrl+V 完成粘贴保存，验证没有文件选择器；通过真实 MediaRecorder 录制测试音轨，验证听写留空时的单句/意群口述、回放及隐藏/切句后的保留。实体设备麦克风仍需实测。

## 单框混排添加与当前片段解析

点「＋ 直接粘贴法语」，在「整段内容」一个框中一起粘贴标题、法语、中文，点击「自动识别并保存」。支持带标签的内容（如标题：、法语：、中文：），也支持标题后中法交替行；模块和日期可随文本填写，否则采用当前模块和当天日期。「预览识别结果」可先核对；识别使用本地规则，不会自动翻译，句数不匹配会提示并将中文保留为整段，避免错误配对。需要时可展开「分栏填写（可选）」修改录入方式。

默认解析只展示当前句或当前意群。点击另一个意群会收起上一处解析；整篇法语、中文与整体备注只有主动点击「查看整篇原文」才展示。单句、意群与整篇的跟读、复述录音以及听写功能均保留。

## 两部分听辨流程

第一部分显示整篇句数、整篇音源和整篇跟读录音；点击「开始跟读听辨」进入第二部分。先选句子，再选意群，只有选中的意群才打开重复播放和跟读录音，文字与解析默认隐藏。点击「查看本意群解析」显示当前片段、可用译文和简短听辨重点。重点来自题目原有注释及本地常见词组/语法规则（通常最多两个规则提示），不会假装对任意粘贴文本生成了完整的人工解析。整句跟读保留在「跟读整句（可选）」中，听写仍可选填。切换意群收起解析并保留本题临时录音；录音可回放、下载和删除。

## 三部分入口与就地解析

统一为 01 整篇听与跟读、02 逐句与意群听辨、03 听写与复述笔记。第一部分右下角只有「开始听音辨写」推进按钮，点击后滚动到第二部分。整篇原文仍可单独开关；移除上方笼统的「当前解析」和页尾的「查看原文与解析」。当前句、当前意群旁的解析按钮均可再次点击收起，切换句子/意群会收起上一处解析。「单句跟读」直接显示，取消「跟读整句（可选）」折叠入口。短句专项、合成段落与真人音源保留各自的播放、跟读录音和听辨重点。合成材料还可按明显的从句连接处提供意群划分建议，人工明确指定的边界保留；真人原音时间轴不因此改变。
